## 数据生成说明

### 生成时间范围
- 从 `2026-02-01` 00:00 至当前日期 23:59

### 数据密度
- 每个自然日生成 24 条数据，分别对应一天中的每小时（00:00 至 23:00）

### 数据内容

#### 1. 蜂箱数据表 (`hive_data`)
- **温度**：15-35度之间随机
- **湿度**：40-90%之间随机
- **内部温度**：比外部高2-5度
- **内部湿度**：比外部高5-15%
- **外部温度**：与温度相同
- **外部湿度**：与湿度相同
- **重量**：10-50kg之间随机，每天略有增长
- **蜜蜂进入**：白天多（6-18时），晚上少
- **蜜蜂离开**：白天多（6-18时），晚上少
- **马蜂检测**：随机，概率较低
- **纬度**：固定值 25.234325（北纬 25°14′3.57″N）
- **经度**：固定值 103.007422（东经 103°0′26.72″E）

#### 2. 物联网遥测数据表 (`iot_telemetry`)
- **设备ID**：`sensor-001` 至 `sensor-005`
- **传感器类型**：
  - `sensor-001`：温度传感器
  - `sensor-002`：湿度传感器
  - `sensor-003`：重量传感器
  - `sensor-004`：蜜蜂计数器（进入和离开）
  - `sensor-005`：马蜂检测传感器
- **数据值**：与蜂箱数据表对应

#### 3. 物联网设备状态表 (`iot_device_status`)
- **设备ID**：`sensor-001` 至 `sensor-005`
- **在线状态**：全部在线
- **最后seen时间**：当前时间
- **信号强度**：-60 至 -75 dBm
- **IP地址**：192.168.1.101 至 192.168.1.105
- **数据包接收**：1000
- **数据包丢失**：1-5

#### 4. 视觉识别数据表 (`vision_recognition`)
- **每天生成2条数据**：上午9点和下午3点
- **图片URL**：模拟URL
- **识别结果**：包含蜜蜂数量、蜂王状态、蜂蜜量、害虫数量

#### 5. 系统配置表 (`system_config`)
- **默认配置**：高德地图API密钥、Qwen API密钥、视频流URL、视频流模式

### 2. 检查数据量
```sql
-- 检查各表数据量
SELECT 'hive_data' AS table_name, COUNT(*) AS total_records FROM hive_data;
SELECT 'iot_telemetry' AS table_name, COUNT(*) AS total_records FROM iot_telemetry;
SELECT 'vision_recognition' AS table_name, COUNT(*) AS total_records FROM vision_recognition;

-- 检查每天数据量
SELECT DATE(FROM_UNIXTIME(timestamp/1000)) AS date, COUNT(*) AS records_per_day 
FROM hive_data 
GROUP BY date 
ORDER BY date;
```

### 3. 检查数据质量
```sql
-- 检查温度范围
SELECT MIN(temperature) AS min_temp, MAX(temperature) AS max_temp FROM hive_data;

-- 检查湿度范围
SELECT MIN(humidity) AS min_humidity, MAX(humidity) AS max_humidity FROM hive_data;

-- 检查重量增长趋势
SELECT DATE(FROM_UNIXTIME(timestamp/1000)) AS date, AVG(weight) AS avg_weight 
FROM hive_data 
GROUP BY date 
ORDER BY date;

-- 检查蜜蜂活动规律
SELECT HOUR(FROM_UNIXTIME(timestamp/1000)) AS hour, AVG(beesIn) AS avg_bees_in, AVG(beesOut) AS avg_bees_out 
FROM hive_data 
GROUP BY hour 
ORDER BY hour;
```

## 注意事项

1. **执行时间**：数据生成过程可能需要几分钟时间，具体取决于生成的数据量
2. **数据库空间**：确保数据库有足够的空间存储生成的数据
3. **重复执行**：如果需要重新生成数据，建议先删除表或清空数据，以避免数据重复
4. **性能影响**：生成大量数据可能会对数据库性能产生暂时影响

## 故障排除

### 常见问题

1. **连接失败**：
   - 检查MySQL服务是否运行
   - 检查用户名和密码是否正确

2. **权限不足**：
   - 确保用户具有创建表和执行存储过程的权限

3. **执行超时**：
   - 对于大量数据生成，可能需要调整MySQL的超时设置

4. **数据重复**：
   - 如果重复执行脚本，可能会生成重复数据
   - 建议在执行前清空表数据

### 解决方法

1. **清空表数据**：
   ```sql
   TRUNCATE TABLE hive_data;
   TRUNCATE TABLE iot_telemetry;
   TRUNCATE TABLE vision_recognition;
   ```

2. **调整MySQL超时设置**：
   ```sql
   SET GLOBAL max_execution_time = 300000; -- 5分钟
   ```

3. **分批生成数据**：
   - 如果数据量太大，可以修改脚本，分批生成数据
