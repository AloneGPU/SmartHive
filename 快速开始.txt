========================================
  智慧蜂场管理系统 - 快速开始指南
========================================

📋 第一步：安装必要软件
----------------------
1. 安装 Node.js（如果还没有）
   - 访问 https://nodejs.org/
   - 下载并安装 LTS 版本
   - 安装完成后重启电脑

2. 安装 MySQL（如果还没有）
   - 访问 https://dev.mysql.com/downloads/mysql/
   - 下载 MySQL Community Server
   - 安装时记住 root 密码

📝 第二步：配置项目
----------------------
1. 在项目根目录创建 .env 文件
   （如果运行 启动项目.bat 会自动创建）

2. 编辑 .env 文件，修改数据库密码：
   DB_PASSWORD=你的MySQL密码

🚀 第三步：启动项目
----------------------
方式一（推荐）：双击运行 "启动项目.bat"

方式二：在命令行运行
   npm start

📊 第四步：插入测试数据（可选）
----------------------
如果想看到示例数据，可以运行：
   插入测试数据.bat

🌐 第五步：访问系统
----------------------
浏览器会自动打开，如果没有，请访问：
   http://localhost:5173

========================================
常见问题：
========================================

Q: 端口被占用怎么办？
A: 修改 .env 文件中的 PORT=3001 为其他端口

Q: 数据库连接失败？
A: 检查 MySQL 服务是否运行，密码是否正确

Q: 页面显示"数据暂未就绪"？
A: 运行"插入测试数据.bat"添加示例数据

Q: 如何停止服务器？
A: 在命令行窗口按 Ctrl+C
