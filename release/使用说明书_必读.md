# 🐝 SmartHive 智慧蜂箱系统 - 落地部署指南

恭喜！您的项目已经具备了完整的后端服务、数据库连接和可视化前端。
为了将这个项目从“开发环境”真正变成“可落地使用”的系统，您需要关注以下四个关键环节。

---

## 1. 硬件数据接入 (最关键的一步)
目前数据库是空的（或只有测试数据）。要让系统“活”起来，您需要将蜂箱上的传感器数据发送给服务器。

### 接口说明
- **目标地址**: `http://<您的服务器IP>:3001/api/beehive`
- **请求方式**: `POST`
- **认证头**: `Authorization: Bearer 123456789` (请在 .env 中修改此 Token)
- **数据格式 (JSON)**:
```json
{
  "temperature": 35.2,    // 温度
  "humidity": 60.5,       // 湿度
  "weight": 24.5,         // 蜂箱重量
  "beesIn": 102,          // 进巢数量
  "beesOut": 98,          // 出巢数量
  "hornetsDetected": 0,   // 胡蜂检测数量
  "latitude": 30.5728,    // (可选) GPS 纬度
  "longitude": 104.0668   // (可选) GPS 经度
}
```

### 硬件端示例 (ESP32/Arduino 伪代码)
```cpp
// 示例：在您的硬件代码中发送数据
http.begin(client, "http://192.168.1.100:3001/api/beehive"); // 替换为电脑/服务器IP
http.addHeader("Content-Type", "application/json");
http.addHeader("Authorization", "Bearer 123456789");

String json = "{\"temperature\":35.2,\"humidity\":60.5,\"weight\":24.5,\"beesIn\":0,\"beesOut\":0,\"hornetsDetected\":0}";
int httpResponseCode = http.POST(json);
```

## 2. 部署方案选择

### 方案 A：本地局域网部署 (最简单，适合测试/家庭农场)
1.  找一台 Windows 电脑作为服务器，保持 24小时开机。
2.  确保这台电脑和您的网关/传感器在**同一个 WiFi 网络**下。
3.  运行 `release/backend` 文件夹下的 `start.bat`。
4.  查询电脑 IP (在命令行输入 `ipconfig`)。
5.  在手机/平板浏览器输入 `http://<电脑IP>:5173` 访问网页。

### 方案 B：云服务器部署 (适合远程监控)
1.  购买一台云服务器 (阿里云/腾讯云等)，安装 Node.js 和 MySQL。
2.  将 `release` 文件夹上传到服务器。
3.  修改 `.env` 文件中的数据库密码。
4.  使用 `pm2` 等工具让服务在后台常驻运行。

---

## 3. 必须修改的配置 (Security)
为了安全，请务必修改 `release/backend/.env` 文件：

1.  **修改 Token**: 将 `API_TOKEN=123456789` 改为一个复杂的密码，防止他人恶意上传垃圾数据。
    *   *注意：修改后，前端网页设置和硬件代码里的 Token 也要同步修改。*
2.  **配置 AI 密钥**: 如果您想用 AI 分析功能，需要去 Google AI Studio 申请一个免费的 API Key，并在前端界面的设置中填入，或者在 `.env` 中配置 `API_KEY=...`。

---

## 4. 常见问题排查

- **前端显示“数据暂未就绪”**:
    - 检查硬件是否通电？
    - 检查硬件代码中的 IP 地址是否正确指向了服务器？
    - 检查 Token 是否匹配？
- **数据库连接失败**:
    - 检查 MySQL 服务是否启动？
    - 检查 `.env` 中的数据库密码是否正确？

---

### 💡 给小白的建议
1.  **先跑通流程**: 不要急着上云。先在家里用电脑当服务器，让 ESP32/传感器成功把数据发给电脑，网页能看到跳动的数据，这就算成功了 90%。
2.  **数据备份**: 定期导出 MySQL 数据库，防止数据丢失。
3.  **循序渐进**: 先关注温湿度和重量，胡蜂识别等高级功能可以等基础稳定后再添加。
